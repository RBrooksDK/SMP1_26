<h1 align="center">Exam</h1>

### Exam prerequisites

None.

### Exam type

The exam is a 4-hour written exam in two parts:

- **Part 1** lasts 3 hours and is a Flowlock exam in Wiseflow.
- **Part 2** lasts 1 hour and is a Wiseflow exam without Flowlock.

You cannot access Part 2 before Part 1 has been concluded. The final grade is based on an overall assessment of Part 1 and Part 2.

The assignments are handed out on paper. You solve Part 1 on paper and Part 2 in Python using a Jupyter Notebook, and you enter your answers in Wiseflow. In addition, you hand in documentation of how you obtained the answers (see below).

### Entering your answers in Wiseflow

- Each task has a numbered heading, e.g. **Assignment 3.2**. The answer field in Wiseflow carries the same number. If a task contains several answer fields, they are numbered (i), (ii), … in the same order as in Wiseflow.
- Each task states the required answer format below the question.
- Enter non-negative integers in the answer fields. If the answer is a fraction, enter the numerator and denominator in their respective fields so that the fraction is irreducible. If an answer is negative, the minus sign is pre-printed in Wiseflow.
- If a decimal value is required, the precision is stated in the task. Round correctly: if the result is 3.485763283 and four decimal places are required, the answer is 3.4858. Use a dot (.) as the decimal separator.
- In multiple-choice tasks, select exactly one option unless otherwise stated.

### Documentation

Unless a task states otherwise, you must document how you obtained each answer. Each student hands in **one PDF file** for Part 1 and **one Jupyter Notebook** for Part 2.

**Part 1: one PDF file**

- Write your calculations by hand, then scan or photograph them and upload them as one PDF file in Wiseflow. The time for scanning and uploading is not part of the 3 hours.
- Present the tasks in numerical order: Assignment 1.1, 1.2, …, 2.1, 2.2, and so on. You may solve the assignments in any order, but the PDF must follow the numbering.
- Mark the answer to each task clearly, e.g. by highlighting it or underlining it twice.

**Part 2: one Jupyter Notebook**

- Write the task number, e.g. *Assignment 13.2*, above the code for that task, and keep the tasks in numerical order.
- Run all cells before you hand in, so that the output is visible to the examiner without running the code again.
- If you solve a task in Part 2 by hand, write this in the notebook at the place of the task, e.g. "Assignment 14: hand-written", and upload the handwritten solution as an additional PDF file for Part 2.

### Tools allowed

In Part 1 you may use any notes, books and other written or printed material, and you will have access to PDF files on your laptop. You may bring your own calculator.

In Part 2 all supplementary materials and aids are allowed, e.g. using a computer as a reference work.

AI tools such as Copilot, ChatGPT and similar are not allowed. Communication of any kind is not allowed during the exam and will lead to expulsion of all involved parties from the exam.
